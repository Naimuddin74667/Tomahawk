# TomahawkTools — Returns Manager

A single-file web app to manage B2C and FBA returns across Flipkart and Amazon.

## Live App
**[Open Returns Manager](https://naimuddin74667.github.io/Tomahawk/Returns-Manager/)**

## Features
- Flipkart B2C returns — Scan → Inspect → Process → Claims
- Amazon FBA returns — Scan → Process → Putaway
- FK Claims Auto-Sync via Claude in Chrome shortcut
- Google Sheets sync (auto-save + manual load)
- Unicommerce CSV export for putaway

## Data
All data syncs to Google Sheets. localStorage is used as local cache.
