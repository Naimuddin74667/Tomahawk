Shopify Label Fixer

Upload the Ekart labels printed from Uniware. The tool writes the Shopify order number (#2879) and one SKU × Qty line per item onto each label. Barcodes, AWB, address and price stay exactly as they are.

Ekart label PDFs
How it works
  1. 1Reads the Shopify order ID and AWB from each label.
  2. 2Looks them up in the Supabase mirror (UC + Shopify, synced every ~15 min).
  3. 3Replaces Order No with the Shopify order # and the product line with SKU × Qty.
  4. 4Labels it can't match are kept unchanged in the PDF and flagged here.
